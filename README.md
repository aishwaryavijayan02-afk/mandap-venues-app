# Mandap & Venues

A mobile-first static web app for browsing auditoriums and event services, managing demo booking requests, and selecting a venue.

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Demo features

- Browse auditorium listings and venue details.
- Save location, theme, and service selections in browser storage.
- Use the demo booking request flow.
- Open the admin image manager at `admin.html`.
- Demo admin login: `admin@demo.com` / `Admin123!`

The admin login and image uploads are browser-only demonstrations, not secure authentication. Uploaded photos are stored in that browser's local storage and are not shared with other users or devices. Do not use real credentials or sensitive images.

Bookings, authentication, payments, and messaging are not connected to a production backend.
